# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

En resumen: trato respetuoso, crítica constructiva al código y no a las personas, y cero
tolerancia al acoso. Los incidentes se reportan en privado al mantenedor a través de
[GitHub](https://github.com/yxd99) y se atienden con confidencialidad.
